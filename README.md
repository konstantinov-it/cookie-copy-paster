# Cookie Copy Paster

Chrome extension for copying cookies between URLs, clearing cookies on the active tab, and automating login with CSS selectors.

## Stack

- React
- Vite
- `@crxjs/vite-plugin`
- Chrome Extension Manifest V3

## Development

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open `chrome://extensions`.
4. Enable `Developer mode`.
5. Load the extension generated by Vite/CRX, or build first and load `dist`.

## Production Build

```bash
npm run build
```

Then load the unpacked extension from `dist`.

## Features

- Copy all cookies or only selected cookie keys.
- Clear cookies for the active tab.
- Save popup state in `chrome.storage.local`.
- Open a login page, fill credentials by selectors, and optionally copy cookies automatically after login.
