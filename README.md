# Cookie Copy Paster

Расширение для Chrome, которое копирует cookie с одного URL на другой. Умеет копировать все cookie или только выбранные по именам, очищать cookie текущей вкладки, а также выполнять авторизацию на странице.

## Возможности
- Копирование cookie между source и destination URL.
- Режим “копировать все” или список ключей.
- Очистка cookie текущей активной вкладки.
- Автоматическая авторизация по URL, логину/паролю и CSS‑селекторам полей/кнопки.
- Сохранение настроек в локальном хранилище расширения.

## Запуск (разработка)
1. Откройте `chrome://extensions`.
2. Включите **Developer mode**.
3. Нажмите **Load unpacked** и выберите папку `d:\dev\extensions\copy-paster`.
4. Откройте попап расширения и заполните поля.
